### B.3 推理基准在不同推理强度下的详细结果

图 [12](#A2.F12) 表明,推理强度设置对输出长度和准确率都能提供平滑、表现良好的控制,并且在全部八个基准上保持一致;这些基准涵盖竞赛数学、科学问答、开放域知识和代码。在长度方面,把强度从 25 调高到 100,每个基准上的平均回复长度都按可预测的方式增长——统一为 $2.0$--$3.1\times$ 的增幅,在 AIME 2026 上从每条回复 4.6k token 增至 11.4k,在 MathArena Apex 2025 上从 29.1k 增至 86.1k——没有失控式增长,也没有异常,因此任何档位的计算成本都可以事先估算。准确率遵循同样平滑的轨迹,在每个基准上都朝正确的方向变化,没有任何基准随强度提高而退化:MathArena Apex 2025 提升 $+40.3$ 分(25.3%$\to$`<!-- -->`{=html}65.6%),Apex 2025 Shortlist 提升 $+11.5$,而即使是已经饱和的基准也保持稳定(GPQA Diamond $+1.3$,LiveCodeBench $+2.6$),AIME 2026 则达到满分 100%。因此,模型提供了一个单一而可靠的旋钮,能以受控且可预测的方式移动成本--准确率的工作点,使每个部署都可以选择与其延迟和计算预算相匹配的强度档位,而不牺牲准确率。

## 附录 C 推理强度控制中的指数 token 惩罚

这个标量强度变量提供了一种部署时的控制手段,用来调节成本--质量的权衡,而不施加硬性的 token 预算。在强化学习期间,较低的强度档位施加更强的 token 惩罚,较高的强度档位则允许更多的计算。本节为指数惩罚调度给出一个简化的动机说明。

对于一条在强度档位 $b$ 下生成、含 $\ell$ 个推理 token 的轨迹,长度扣分为

  -- ----------------------------------------------------------------------------------------------- -- ------
     $$r^{\mathrm{len}}(\ell,b)=-\min\left\{C_{\max},k(b)\frac{\ell}{L_{\mathrm{norm}}}\right\},$$      (11)
  -- ----------------------------------------------------------------------------------------------- -- ------

其中 $L_{\mathrm{norm}}$ 是参考长度,$C_{\max}$ 为扣分设定上限。与强度相关的 token 惩罚系数为

  -- ---------------------------------------------------------- -- ------
     $$k(b)=k_{0}\exp\left(-\frac{b-b_{\min}}{\tau}\right),$$      (12)
  -- ---------------------------------------------------------- -- ------

其中 $k_{0}$ 是最低强度档位 $b_{\min}$ 处的惩罚系数,$\tau$ 控制惩罚衰减的速率。

为说明这一选择的动机,考虑一个固定的问题 $x$。令 $p_{x}(\ell)$ 表示经过 $\ell$ 个推理 token 之后该问题被解出的概率。在未触及上限的区域内,将偏好的推理长度 $\ell_{x}^{*}(b)$ 定义为

  -- -------------------------------------------------------------------------------------------------------------- -- ------
     $$\ell_{x}^{*}(b)\in\arg\max_{\ell\geqslant 0}\left[p_{x}(\ell)-k(b)\frac{\ell}{L_{\mathrm{norm}}}\right].$$      (13)
  -- -------------------------------------------------------------------------------------------------------------- -- ------

对于内部最优解,一阶条件为

  -- ---------------------------------------------------------------------------------- -- ------
     $$p_{x}^{\prime}\!\left(\ell_{x}^{*}(b)\right)=\frac{k(b)}{L_{\mathrm{norm}}},$$      (14)
  -- ---------------------------------------------------------------------------------- -- ------

其中 $p_{x}^{\prime}(\ell)=dp_{x}(\ell)/d\ell$ 是额外推理给解出概率带来的边际提升。

我们假设,在相关的工作范围内,这一边际收益近似按指数衰减:

  -- ---------------------------------------------------------------------------- -- ------
     $$p_{x}^{\prime}(\ell)\approx a_{x}\exp\left(-\frac{\ell}{s_{x}}\right),$$      (15)
  -- ---------------------------------------------------------------------------- -- ------

其中 $a_{x}>0$ 是与具体实例相关的尺度,$s_{x}>0$ 决定衰减速率。将式 ([12](#A3.E12)) 和式 ([15](#A3.E15)) 代入式 ([14](#A3.E14)),得到

  -- ---------------------------------------------------------------------------------- -- ------
     $$\ell_{x}^{*}(b)\approx C_{x}-s_{x}\log k_{0}+\frac{s_{x}}{\tau}(b-b_{\min}),$$      (16)
  -- ---------------------------------------------------------------------------------- -- ------

其中 $C_{x}=s_{x}\log(a_{x}L_{\mathrm{norm}})$ 与 $b$ 无关。因此,在这一局部模型下,指数惩罚调度会在所请求的强度与偏好的推理长度之间产生一个简单的一阶仿射趋势。

对于两个强度档位 $b_{2}>b_{1}$,相应的预测长度差为

  -- ------------------------------------------------------------------------------------ -- ------
     $$\ell_{x}^{*}(b_{2})-\ell_{x}^{*}(b_{1})\approx\frac{s_{x}}{\tau}(b_{2}-b_{1}).$$      (17)
  -- ------------------------------------------------------------------------------------ -- ------

由此可见,$k_{0}$ 主要控制趋向更短推理的总体压力,而 $\tau$ 控制预测中对强度的敏感度。

这一推导是奖励层面的局部近似,并不是断言实测的平均长度必须是线性的或逐点单调的。实际表现可能出现偏离,原因包括:强度指令可以直接改变推理策略,生成具有随机性,智能体轨迹包含的轮数各不相同,以及子组奖励归一化会改变优化强度。该分析还假设存在内部解,此时惩罚上限并未生效。一旦达到上限,边际 token 惩罚变为零,被上限截断的区域必须单独考虑。
